# How to Customize the Numeric Axis of Blazor Charts

## Overview

This sample demonstrates how to customize the numeric axis in Syncfusion [Blazor Chart](https://www.syncfusion.com/blazor-components/blazor-charts). The application shows how numeric-axis values can be configured to control chart presentation and data visualization behavior. The sample focuses on numeric-axis configuration techniques such as axis label formatting, range padding customization, custom interval settings, and displaying chart data based on user-defined axis ranges.

The project is implemented as a Blazor application and provides a practical reference for developers who want to customize numeric-axis behavior in Syncfusion Blazor Chart components.

## Key Features

- Demonstrates numeric-axis configuration in Syncfusion Blazor Charts.
- Shows how to format numeric-axis labels for improved readability.
- Demonstrates range-padding customization for chart axes.
- Shows how to define custom numeric-axis ranges.
- Demonstrates the use of custom interval values on the axis.
- Illustrates displaying chart data based on customized x-axis range values.
- Uses Syncfusion Blazor Chart components to render numeric-axis based visualizations.
- References the Syncfusion Numeric Axis feature implementation documented for Blazor Charts.

## Prerequisites

- Visual Studio 2022 or Visual Studio Code
- .NET SDK compatible with the project's target framework

## How to Run the Project

**Visual Studio 2022**

1. Clone or download this repository.
2. Open `CustomNumericAxis.sln`.
3. Restore all NuGet packages.
4. Set the `CustomNumericAxis` project as the startup project if required.
5. Build the solution.
6. Run the application using `Ctrl+F5`.

**Visual Studio Code**

1. Open the repository folder in Visual Studio Code.
2. Open the integrated terminal.
3. Navigate to the repository root containing `CustomNumericAxis.csproj`.

```bash
dotnet restore
dotnet run
```

4. Open the local application URL displayed in the terminal after the application starts.
