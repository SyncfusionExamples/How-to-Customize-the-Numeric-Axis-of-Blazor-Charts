# How to Customize the Numeric Axis of Blazor Charts

## Project Overview
This project is designed to help developers learn how to work with numeric axes in Blazor Charts. It focuses on configuring axis-related properties such as label formatting, range padding, custom intervals, and defining custom X-axis ranges. The sample is useful for understanding how numeric values are displayed and controlled in data visualizations built with Blazor and Syncfusion components.

The application serves as a practical learning reference and is aligned with the official Syncfusion Blazor Chart documentation and demos.

## Features
- Add a numeric axis to Blazor Charts  
- Customize numeric axis labels and formatting  
- Define custom axis intervals and ranges  
- Apply range padding to control data presentation  
- Display data points within a specified X-axis range  

## Prerequisites
To run this application, ensure you have the following installed:
- Visual Studio 2022  
- .NET SDK compatible with Blazor projects  
- Basic knowledge of Blazor and C#  

## Installation
1. Check out this repository to a local directory.
2. Open the solution file using Visual Studio 2022.
3. Restore the required NuGet packages by rebuilding the solution.
4. Ensure all dependencies are resolved successfully.

## Usage
Run the project from Visual Studio to launch the Blazor application. The chart displayed in the sample demonstrates how numeric axes can be customized. You can review and modify the axis configuration in the source code to better understand how each property affects the chart behavior.
